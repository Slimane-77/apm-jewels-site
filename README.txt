DESCRIPTION DU SITE

Panthère Jewels est un site e-commerce de bijoux de luxe
développé dans le cadre d'un projet web de fin d'année.

Le site propose une expérience d'achat élégante et intuitive
autour de 5 catégories de bijoux : colliers, bagues,
pendentifs, bracelets et boucles d'oreilles.

Il comprend les fonctionnalités suivantes :

  - Page d'accueil avec présentation de la boutique
  - Section "À propos"
  - Catalogue produits avec filtrage par catégorie
    et défilement horizontal par collection
  - Aperçu rapide des produits au survol
  - Panier d'achat avec gestion des quantités,
    suppression de produits et calcul du total
  - Système de code promo
  - Formulaire de commande en 3 étapes
    (livraison, paiement, confirmation)
  - Section contact avec formulaire validé
  - Système de connexion et d'inscription
    avec sauvegarde des données en localStorage
  - Gestion de session utilisateur

INSTRUCTIONS D'UTILISATION

1. LANCER LE SITE

2. NAVIGATION
   Utiliser la barre de navigation en haut pour accéder
   aux sections : Accueil, À propos, Produits, Contact.

3. CONNEXION / INSCRIPTION
   Cliquer sur "Connexion" dans la barre de navigation.
   Créer un compte ou se connecter avec le compte démo :
     Email    : demo@jewels.fr
     Mot de passe : demo123
   Après connexion, le bouton devient un avatar avec
   un menu déroulant (profil, panier, déconnexion).

4. FILTRER LES PRODUITS
   Dans la section Produits, cliquer sur les boutons
   de catégorie (Colliers, Bagues, etc.) pour filtrer
   l'affichage. Les flèches permettent de faire défiler
   les produits horizontalement.

5. APERÇU RAPIDE
   Survoler un produit et cliquer sur "Aperçu rapide"
   pour voir l'image en grand dans une fenêtre.

6. AJOUTER AU PANIER
   Cliquer sur "Acheter" sur un produit pour l'ajouter
   au panier. Une notification s'affiche en bas à droite.
   Accéder au panier via l'icône en haut ou le bouton
   "Voir mon panier" en bas de la section produits.

7. GÉRER LE PANIER
   Dans le panier, modifier les quantités avec + et -,
   supprimer un article avec l'icône poubelle.
   Un code promo peut être appliqué (ex: JEWELS10,
   LUXE15, VIP20).

8. PASSER COMMANDE
   Cliquer sur "Procéder au paiement" et suivre les
   3 étapes : adresse de livraison, informations de
   paiement, confirmation.

9. CONTACT
   Remplir le formulaire dans la section Contact
   et cliquer sur "Envoyer le message".
